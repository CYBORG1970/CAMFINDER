# CAMFINDER
The goal is to create a GUI that facilitates the study of how—by capturing packets with the Aircrack-ng suite—one can identify cameras and NVRs connected via LAN or Wi-Fi without needing the Wi-Fi password.
It must also detect cascaded routers and perform the same task for them.
The software should capture the handshakes of detected Wi-Fi networks and ultimately generate a diagram visualizing the entire network (routers, Wi-Fi, and LAN).
This software is intended solely for educational purposes regarding Wi-Fi/LAN/router networks created in a laboratory setting and must not be used for malicious or illegal activities.
